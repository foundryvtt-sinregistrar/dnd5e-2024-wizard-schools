# D&D 2024 — Wizard Schools

[![Latest release](https://img.shields.io/github/v/release/foundryvtt-sinregistrar/dnd5e-2024-wizard-schools?label=release)](https://github.com/foundryvtt-sinregistrar/dnd5e-2024-wizard-schools/releases/latest)

Adds the Conjurer, Enchanter, Necromancer, and Transmuter Wizard subclasses to the 2024 Wizard progression.

## Status

Compatible with Foundry VTT 14.367 or newer and dnd5e 6.0.3 or newer. Version 2.14.1 was verified with Foundry VTT 14.369.

## Requirements

- Foundry VTT 14.367 or newer.
- The dnd5e system 6.0.3 or newer.
- The official *Dungeons & Dragons Player's Handbook* (PHB 2024) module, which provides the 2024 Wizard class and spell content.

## Installation

Install from Foundry's Add-on Modules browser:

```text
https://github.com/foundryvtt-sinregistrar/dnd5e-2024-wizard-schools/releases/latest/download/module.json
```

Enable the module alongside dnd5e and PHB 2024.

## Activation and use

The native **D&D 2024 - Wizard Schools** compendium contains 24 documents in four folders. Add a subclass and its features to a Wizard from the compendium.

| Subclass | Level 3 | Level 6 | Level 10 | Level 14 |
| --- | --- | --- | --- | --- |
| Conjurer | Conjuration Savant, Minor Conjuration | Benign Transposition | Focused Conjuration | Durable Summons |
| Enchanter | Enchantment Savant, Hypnotic Gaze | Instinctive Charm | Split Enchantment | Alter Memories |
| Necromancer | Necromancy Savant, Grim Harvest | Undead Thralls | Inured to Undeath | Command Undead |
| Transmuter | Transmutation Savant, Minor Alchemy | Transmuter's Stone | Shapechanger | Master Transmuter |

## Updating

From the 1.14.x series, update to 2.14.0 or newer and install a translation module if needed. IDs, UUIDs, formulas, automation identifiers, and ItemGrant links remain stable; imported copies do not synchronize automatically.

## Included content

All four schools include advancements at levels 3, 6, 10, and 14. The base module is English; for Spanish, install `translate-dnd5e-wizard-schools-2024-es` together with Babele.

## Limitations

Foundry does not synchronize actor copies already imported from the compendium.
