English

Bring four classic Wizard schools into the D&D 2024 subclass progression in Foundry VTT. This community module adapts the Conjurer, Enchanter, Necromancer, and Transmuter subclasses from the 2014 Player's Handbook for use with the 2024 Wizard.

What the module adds

  • Four Wizard subclasses: Conjurer, Enchanter, Necromancer, and Transmuter.
  • Native compendium: 24 Item documents (4 subclasses and 20 class features), organized into four folders.
  • 2024 advancement: Subclass features granted at Wizard levels 3, 6, 10, and 14 through native ItemGrant advancements.
  • Activities and effects: Subclass features include the related activities, effects, and supported optional automation described in the repository.
  • Stable references: Existing Item and advancement identifiers are retained across the documented migration.

The four schools

  • Conjurer (Conjuration): Minor Conjuration, Benign Transposition, Focused Conjuration, and Durable Summons.
  • Enchanter (Enchantment): Hypnotic Gaze, Instinctive Charm, Split Enchantment, and Alter Memories.
  • Necromancer (Necromancy): Grim Harvest, Undead Thralls, Inured to Undeath, and Command Undead.
  • Transmuter (Transmutation): Minor Alchemy, Transmuter's Stone, Shapechanger, and Master Transmuter.

Requirements and installation

Foundry VTT 14.367+ (manifest verified 14.370), dnd5e 6.0.3+ (verified 6.0.6), and the official D&D Player's Handbook 2024 module (minimum 2.2.0, required separately).

  1. Install a compatible D&D5e system and the official Player's Handbook 2024 module.
  2. Install this module using Foundry's Add-on Modules browser or the manifest URL below.
  3. Activate both modules in your world. Open the D&D 2024 - Wizard Schools compendium and add the desired subclass to a 2024 Wizard.

Manifest: Latest release module.json

Spanish translation

The base compendium is in English. For Spanish text, install the separate Wizard Schools Spanish Translation module and Babele.

Important notes

Imported subclass and feature copies already on an Actor do not update automatically when the source compendium changes. The module does not replace or modify official compendiums. The MIT license covers the module's software code; third-party D&D rules text is not relicensed by it.

Español

Incorpora cuatro escuelas clásicas de Mago a la progresión de subclases de D&D 2024 en Foundry VTT. Este módulo comunitario adapta las subclases Conjurador, Encantador, Nigromante y Transmutador del Manual del Jugador de 2014 a la progresión del Mago de 2024.

Qué añade el módulo

  • Cuatro subclases: Conjurador, Encantador, Nigromante y Transmutador.
  • Compendio nativo: 24 documentos de tipo Item (4 subclases y 20 rasgos), organizados en cuatro carpetas.
  • Progresión de 2024: Rasgos concedidos en los niveles de Mago 3, 6, 10 y 14 mediante avances nativos ItemGrant.
  • Actividades y efectos: Los rasgos incorporan sus actividades, efectos y automatizaciones opcionales compatibles descritas en el repositorio.
  • Referencias estables: Se mantienen los identificadores de Items y avances durante la migración documentada.

Las cuatro escuelas

  • Conjurador: Conjuration Savant, Minor Conjuration, Benign Transposition, Focused Conjuration y Durable Summons.
  • Encantador: Enchantment Savant, Hypnotic Gaze, Instinctive Charm, Split Enchantment y Alter Memories.
  • Nigromante: Necromancy Savant, Grim Harvest, Undead Thralls, Inured to Undeath y Command Undead.
  • Transmutador: Transmutation Savant, Minor Alchemy, Transmuter's Stone, Shapechanger y Master Transmuter.

Los nombres de los rasgos se muestran aquí en inglés porque el módulo base distribuye su compendio en ese idioma.

Requisitos e instalación

Foundry VTT 14.367+ (verificado 14.370 según el manifiesto), dnd5e 6.0.3+ (verificado 6.0.6) y el módulo oficial D&D Player's Handbook 2024 (mínimo 2.2.0, instalación por separado).

  1. Instala el sistema D&D5e compatible y el módulo oficial Player's Handbook 2024.
  2. Instala este módulo desde el gestor de complementos de Foundry o con el manifiesto indicado.
  3. Activa ambos módulos en el mundo. Abre el compendio D&D 2024 - Wizard Schools y añade la subclase al personaje Mago de 2024.
